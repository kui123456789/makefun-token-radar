How the value is worked out

Size uses a square root, so doubling TVL lifts value by about 41%, not 100%. Growth uses a soft cap: a +200% week is worth at most about 1.85×, a −60% week costs about two thirds. Maturity is an S-curve in days since listing. A small bonus rewards multi-chain reach, and the category factor adjusts for risk. Every factor comes from the snapshot's own figures — no protocol is ever special-cased by name.

Implied value is this entry's own claim about what a token would be worth if the protocol's record stayed as it is. It is not a prediction that a token will be issued, or when.
