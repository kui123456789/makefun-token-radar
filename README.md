Early Radar ranks 200 pre-token protocols from a frozen DefiLlama snapshot by an implied token value computed from TVL, 7-day growth, age, chain reach and category, and shows a concrete farm plan for each one in a no-network dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input snapshot.json
```
